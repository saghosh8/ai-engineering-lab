# AI Engineering Lab

Hands-on, practical builds pairing real engineering problems with small,
focused AI-powered solutions — one problem, one small system, no forced
agents or RAG unless they genuinely earn their place.

Each folder below corresponds to a newsletter article. Code is meant to
be read alongside the article, not instead of it.
