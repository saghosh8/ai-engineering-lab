Practical builds that give an LLM controlled, read-only access to
Kubernetes cluster state to help with investigation and troubleshooting.
Deterministic code handles all cluster interaction; the AI is used only
where correlation across unstructured evidence (logs, event messages)
genuinely benefits from a model.
